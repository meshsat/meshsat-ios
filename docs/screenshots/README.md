# Screenshots

Public screenshots of MeshSat iOS (README, meshsat.net, docs.meshsat.net) are
taken on a real iPhone, never in the simulator, and never mocked or composited.

- Folder per capture date: `docs/screenshots/YYYY-MM/NN-name.png`, numbered in
  the order the README shows them.
- Every retake gets a new file name. The website caches images for a year.
- Each set has a caption with the app version, the phone model and the date.
- Redact before committing: IMEIs, positions, node ids, phone numbers, e-mail
  addresses, certificate details and any `nllei01*` host name. Blur, do not
  crop, so the layout stays honest.
- Simulator captures from the parity test suite go under
  `docs/screenshots/simulator/` and are never used on a public surface.

Until the first build runs on an iPhone this folder holds no images, and the
README says so instead of showing placeholders.
